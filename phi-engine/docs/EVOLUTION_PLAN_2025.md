## 📊 ЭТАП 2: БЕНЧМАРКИ (МЕСЯЦЫ 2-3)

### Цель:
Создать бенчмарки для всех 11 решений и сравнить с альтернативами.

### Действия:

#### Бенчмарк 1: Golden Wrap vs Обычные Trit Operations
**Метрики**:
- Время сложения тритов.
- Время вычитания тритов.
- Время обертки (wrap-around).

**Сравнение**:
- `Phi-Engine` (O(1) lookup) vs `TVC Runtime` (if-ы).

**Ожидаемый результат**:
- `Phi-Engine`: 1ns.
- `TVC Runtime`: 100ns.
- **Ускорение**: 100×.

---

#### Бенчмарк 2: SIMD Ternary vs Циклы
**Метрики**:
- Время сложения 32 тритов.
- Время максимума 32 тритов.

**Сравнение**:
- `Phi-Engine` (SIMD 32×) vs `NumPy` (векторные операции).

**Ожидаемый результат**:
- `Phi-Engine`: 100ns (одна AVX2 инструкция).
- `NumPy`: 3200ns (32 циклов).
- **Ускорение**: 32×.

---

#### Бенчмарк 3: AMR Resize vs Линейный Рост
**Метрики**:
- Количество копирований при росте массива (от 100 до 100000).
- Объем используемой памяти.

**Сравнение**:
- `Phi-Engine` (φ = 1.618) vs `std.ArrayList` (×2 growth).

**Ожидаемый результат**:
- `Phi-Engine`: 61.8% Memory Savings.
- `std.ArrayList`: 0% (линейный рост ×2).

---

#### Бенчмарк 4: Fibonacci Hash vs Redis
**Метрики**:
- Количество коллизий при вставке 10000 ключей.
- Время вставки и поиска.

**Сравнение**:
- `Phi-Engine` (Fibonacci hashing) vs `Redis` (Murmur3, FNV-1a).

**Ожидаемый результат**:
- `Phi-Engine`: 100 коллизий (оптимально).
- `Redis`: 200 коллизий.
- **Ускорение**: 10-20%.

---

#### Бенчмарк 5: Lucas Numbers vs NumPy
**Метрики**:
- Время вычисления L(10000).
- Время вычисления L(100000).

**Сравнение**:
- `Phi-Engine` (O(1) lookup для n < 20) + O(n) для n >= 20) vs `NumPy` (векторизация).

**Ожидаемый результат**:
- `Phi-Engine`: 100µs.
- `NumPy`: 1000µs.
- **Ускорение**: 10×.

---

### Инструменты для бенчмарков:
- `zig test -fbenchmark`
- `hyperf` (Linux) или `xctrace` (macOS).
- `Criterion.rs` (для Rust сравнений).
